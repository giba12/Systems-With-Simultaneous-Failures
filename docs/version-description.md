## 1. Scope

### 1.1 Identification
Space System Reliability Analyzer: C++20 library `reliability`, command-line tool `analyze`, Python experiment layer, tests
and documents. Educational; the analysed satellite is fictional and nothing here is flight-qualified.

### 1.2 System overview
Exact per-state signature and MTTF analysis of coherent binary systems under independent or common-cause failures, with an
independent verification mode, repair-policy comparison and seven pre-registered experiments. See [conops.md](conops.md).

### 1.3 Document overview
Section 3 lists what this version contains, what changed since the first commit, installation steps and known problems.

### 3.6 Installation instructions

Needs a Linux machine, a C++20 compiler (g++ 13 and clang++ 18 tested), CMake ≥ 3.20, Python 3, and network access for the first configure.

```bash
cmake -S project -B project/build -DCMAKE_BUILD_TYPE=Release
cmake --build project/build --parallel
ctest --test-dir project/build --output-on-failure     # expect 129 tests, all passing
project/demo.sh                                         # optional tour
```

For the analysis and plots of the experiments:

```bash
cd project
python3 -m venv .venv && .venv/bin/pip install -r python/requirements.txt
python3 python/run_experiments.py all
.venv/bin/python python/analyze_results.py
.venv/bin/python python/plot_results.py
```

There is no install target and nothing is written outside the checkout. To remove the software, delete the directory.

### 3.7 Possible problems and known errors

**Limits (by design):** components are assumed identical; n ≤ 24 for any analysis, n ≤ 16 for common-cause models and for
`--verify`, n ≤ 20 for repair policies; failure models are [Exp] and the six common-cause models of Table I; Linux only
(other operating systems not tried); run times are orders of magnitude from one laptop. See the [deviation log](deviation-log.md).

## 4. Notes

- The Python tests that need pandas or matplotlib skip themselves when those packages are missing (43 run, 8 skip with the standard library only).
- Timing-based experiment predictions (Experiment 4) can flip between runs; this is documented in the experiment report §6.1.
- Results are for a **fictional** system and must not be quoted as a statement about any real spacecraft.
